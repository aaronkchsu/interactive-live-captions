# Caption fonts

22 unmodified font binaries distributed by Google Fonts, downloaded November 1, 2026. `catalog.json` records the exact binary source URLs, families, and weights. Each font has an adjacent OFL or Apache license file; retain these when distributing the app. The shared picker also offers native Georgia and monospace, for 24 choices total, plus an installed-font option.

Source and redistribution guidance: https://github.com/google/fonts#self-host-fonts-available-from-google-fonts

Fonts load on demand from the local server in both studio and OBS. No Google Fonts request is made by this caption-font loader. This does not change existing remote UI-font imports elsewhere. Script coverage varies; missing glyphs use the browser's fallback. Custom fonts must be installed on the studio/OBS computer and are not uploaded or bundled automatically.
